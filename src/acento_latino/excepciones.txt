# Excepciones de acento-latino
# Formato: palabra o frase = como debe leerse
# Se aplican antes de las reglas automaticas (c->s, z->s, x->ks, ll->y) y su
# resultado no se vuelve a tocar. Mayusculas y minusculas dan igual en la
# izquierda. Las frases largas ganan sobre las cortas.
# Si una lectura suena mal en tu modelo, cambiala con tu propio archivo:
#   acento-latino guion.txt -e mis_excepciones.txt
#
# Estado de cada lectura: las secciones "VALIDADAS" se escucharon con el modelo
# indicado y sonaron bien; el resto son PROPUESTAS sin escuchar todavia.
# Una lectura buena en un modelo puede sonar mal en otro. Si validas o corriges
# una, cuentanos como en CONTRIBUTING.md.
